# Luck-Mail 主界面（按用户上传 webmail_client__2.html 重做）

自写前端、假数据演示，后端未接线。部署在 https://mm.ynzb.cn/（nginx 容器 luck-mail-frontend，/opt/luck-mail/frontend/）。

## 结构
- 4 栏（桌面 >1024px）：最左窄栏系统导航（头像/设置/改密码/退出）+ 左栏导航树（Logo + 写信 + 聚合分类 + 邮箱账号）+ 邮件列表 + 阅读窗。蓝色系 Tailwind + FontAwesome（与上传文件一致）。
- 聚合分类：所有收件箱、所有未读、所有草稿、所有已发送、所有已删除（按上传文件；不加最近查看、红旗）。
- 邮箱列表平铺，无分组、无分组管理入口（用户要求去掉分组功能）。

## 响应式
- 平板 768–1024px：收起最左窄栏，邮件列表收窄到 260px，设置/改密码/退出移到左栏底部。
- 手机 <768px：单栏钻取式（body[data-mview]：nav 邮箱导航 → list 邮件列表 → read 阅读窗），每级有返回按钮。
